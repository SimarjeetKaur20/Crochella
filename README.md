# Crochella – Handmade Crochet Store

## About the Project
Crochella is a Pinterest-inspired e-commerce website for a handmade crochet business. It provides a beautiful and user-friendly platform where customers can explore crochet products, check prices, add items to their shopping cart, and place orders online.

The website features a soft pastel aesthetic with elegant typography, attractive product images, and a cozy handmade-boutique design.

## Features

- **Pinterest-Inspired Design:** Aesthetic layout with pastel colors and an attractive product gallery.
- **Product Catalog:** Browse crochet bags, coasters, table mats, thaal posh, scrunchies, crochet toys, and more.
- **Product Details:** View product images, descriptions, prices, colors, sizes, and availability.
- **Search and Filters:** Find products by name, category, or price.
- **Shopping Cart:** Add products, change quantities, remove items, and view the total price.
- **Admin Dashboard:** Securely add, edit, delete, and manage products without changing the code.
- **Order Management:** View customer orders, delivery details, payment status, and order progress.
- **Checkout:** Enter customer and delivery details to place an order.
- **Responsive Design:** Works on mobile phones, tablets, and desktop computers.
- **Payment Integration:** Supports online payments through Razorpay when configured, with optional Cash on Delivery or WhatsApp ordering.

## Technology Stack

- **Frontend:** React, TypeScript, Tailwind CSS
- **Backend and Database:** Supabase, PostgreSQL
- **Image Storage:** Supabase Storage
- **Authentication:** Secure admin login
- **Payment Gateway:** Razorpay (optional)
- **Deployment:** Vercel

## How It Works

1. Customers visit the website and explore available crochet products.
2. They select products, check prices, and add items to their cart.
3. They enter their delivery details and choose an available ordering method.
4. The order is saved and becomes visible in the admin dashboard.
5. The store owner manages products, inventory, and order status through the dashboard.

## Installation and Setup

1. Clone or download the project repository.
2. Install the required dependencies using `npm install`.
3. Configure the Supabase project, database, storage, and authentication.
4. Add the required environment variables to the `.env` file.
5. Start the development server using `npm run dev`.

*Note: Exact setup commands and environment variables may vary depending on the project structure. Payment and deployment require additional configuration.*

## Project Goal

The goal of Crochella is to help a handmade crochet business showcase its products professionally, manage its catalog easily, and provide customers with a convenient online shopping experience.
